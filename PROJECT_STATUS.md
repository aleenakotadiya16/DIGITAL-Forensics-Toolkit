## 📋 Quick Reference

### Generate Lazy Loading Portal (Fastest)
```bash
python3 scripts/generate_unified_portal.py \
  --agency "Agency Name" \
  --photos input/CASE/photos/ \
  --documents input/CASE/documents/ \
  --output output/CASE/ \
  --lazy-loading
```

### Generate Single-File Portal (Easy Distribution)
```bash
python3 scripts/generate_single_file_portal.py \
  --agency "Agency Name" \
  --photos input/CASE/photos/ \
  --documents input/CASE/documents/ \
  --output output/CASE/ \
  --optimized
```

### Start Web Server (for Lazy Loading)
```bash
cd output/CASE/
python3 -m http.server 8000
# Open: http://localhost:8000/unified-forensic-portal-lazy.html
```

## 💡 Key Learnings & Best Practices

### Technical Lessons
✅ **Lazy loading** is essential for large evidence sets (98% faster)
✅ **150 DPI** is optimal balance for documents (quality vs size)
✅ **350px metadata sidebar** works well on desktop
✅ **row-reverse flex** puts metadata on left (better UX)
✅ **Fixed modal dimensions** prevent layout issues

### Workflow Lessons
✅ **Always copy, never move** original evidence
✅ **Checksums before and after** every step
✅ **Document everything** in processing logs
✅ **Test on multiple browsers** before delivery
✅ **Mobile test with DevTools** for quick validation

### Documentation Lessons
✅ **Protocol documents** ensure consistency
✅ **Sample workflows** teach better than abstract guides
✅ **CLAUDE.md** accelerates future AI sessions
✅ **Inline comments** in scripts help maintainability
