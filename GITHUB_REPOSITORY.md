## 💻 Clone & Use

### Clone the Repository
```bash
# HTTPS
git clone https://github.com/Jobikinobi/DIGITAL-Forensics-Toolkit.git

# SSH (if configured)
git clone git@github.com:Jobikinobi/DIGITAL-Forensics-Toolkit.git

# GitHub CLI
gh repo clone Jobikinobi/DIGITAL-Forensics-Toolkit
```

### Get Started
```bash
cd DIGITAL-Forensics-Toolkit

# Read getting started guide
cat GETTING_STARTED.md

# Install dependencies
pip3 install Pillow PyMuPDF
brew install exiftool

# Process your first case
python3 scripts/generate_unified_portal.py
```
